iPhone / iPad

  1. Tap Copy user ID above.
  2. Open Settings → Wi-Fi and tap eduroam.
  3. Paste the user ID, then type the password from the sheet.
  4. Tap Join, then Trust on the certificate prompt.

Copy the user ID before opening Settings. Switching back to this page closes the Wi-Fi login window.

Android

  1. Tap Copy user ID above.
  2. Open Settings → Wi-Fi and tap eduroam.
  3. Choose these settings:
    • EAP method: PEAP
    • Phase 2 authentication: MSCHAPV2
    • CA certificate: Use system certificates
    • Domain: univie.ac.at
    • Identity: paste the user ID
    • Anonymous identity: leave empty
    • Password: from the sheet
  4. Tap Connect.

On some phones, Phase 2 is hidden under Advanced options.
